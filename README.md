# Demo de mapa de barrios

Aplicación de ejemplo que muestra en un mapa los barrios de Cuidad del Este obtenidos desde una API.

El proyecto está dividido en dos partes:

- [`frontend/`](frontend/README.md): interfaz desarrollada con Vite y JavaScript.
- [`backend/`](backend/README.md): API con Express y PostgreSQL + PostGIS que expone los datos de los barrios.

Consulta el README de cada directorio para instalar las dependencias e iniciar sus servicios.
